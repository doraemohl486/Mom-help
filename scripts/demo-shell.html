📩 엄마 폰에 문자 오기

실제 앱에서는 부모님 폰의 병원 예약 문자가 자동으로 넘어와요. 여기서 흉내 내 보세요.

해보기 순서
  1. 👵 엄마 화면에서 🚕 택시 → 예약 → 지금 바로 불러줘
  2. 👩 자녀 화면 'AI 통화 내용'에서 AI와 콜센터 대화 보기
  3. '+ 일정 추가' → 📋 예약 문자 붙여넣기 → 자동으로 채우기
  4. 같은 일정을 한 번 더 저장 → 중복 팝업
  5. 👵 엄마 화면 📝 일정 알려주기 → "다음주 화요일 오전 10시 서울대병원"
  6. 위 📩 문자 오기 → 자동으로 일정 생성 / 중복은 건너뜀
  7. 자녀 화면 맨 아래 '배차 불가' 고르고 택시 → 3번 재시도 후 자녀에게

체험판은 실제 전화를 걸지 않고 가상 콜센터와 통화해요. 운영 시간 제한도 없어요 (실제는 8~22시). 문자 읽기와 AI 통화는 규칙 기반으로 동작하고, 장소는 샘플 10곳만 찾을 수 있어요 (서울대학교병원, 세브란스병원, 서울아산병원, 삼성서울병원, 강남세브란스병원, 서울성모병원, 일산병원, 마포구청, 서울역, 탑골공원). 입력한 내용은 이 브라우저에만 저장돼요.
