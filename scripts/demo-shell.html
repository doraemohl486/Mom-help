📩 엄마 폰에 문자 오기

실제 앱에서는 부모님 폰의 병원 예약 문자만 자동으로 넘어와요. 모임·경조사 같은 개인 문자는 남기지 않아요. 여기서 흉내 내 보세요.

해보기 순서
  1. 👵 엄마 화면에서 🚕 택시 → 예약 → 지금 바로 불러줘
  2. 👩 자녀 화면 'AI 통화 내용'에서 AI와 콜센터 대화 보기
  3. '+ 일정 추가' → 📋 예약 문자 붙여넣기 → 자동으로 채우기
  4. 같은 일정을 한 번 더 저장 → 중복 팝업
  5. 👵 엄마 화면 📝 일정 알려주기 → "토요일 낮 12시 종로에서 동창 모임" → 엄마 폰에만 있고 자녀 화면에는 안 보여요 (병원 일정은 보여요)
  6. 위 📩 문자 오기 → 병원 예약은 자동으로 일정 생성 / 중복은 건너뜀 / 동창회 같은 개인 문자는 안 가져옴
  7. 자녀 화면 맨 아래 '배차 불가' 고르고 택시 → 3번 재시도 후 자녀에게

체험판은 실제 전화를 걸지 않고 가상 콜센터와 통화해요. 운영 시간 제한도 없어요 (실제는 8~22시). 문자 읽기와 AI 통화는 규칙 기반으로 동작하고, 장소는 샘플 10곳만 찾을 수 있어요 (큰 병원 7곳, 마포구청, 서울역, 탑골공원, 망원시장, 명동성당, 서울노인복지센터, 롯데마트 서울역점). 검색 버튼을 누르면 AI가 다른 곳도 찾아봐요. 입력한 내용은 이 브라우저에만 저장돼요.
